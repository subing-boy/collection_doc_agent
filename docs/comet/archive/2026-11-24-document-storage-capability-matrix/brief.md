# 目标

在 `README.md` 项目说明文档、终端控制台提示（`main.py`）以及代码各处，全面补充并规范化“个人文档管家”的【存储能力边界矩阵（Storage Capability Matrix）】：
1. 明确列出已原生深度支持的 6 大核心办公格式（`.docx`, `.pptx`, `.xlsx`, `.msg`, `.md`, `.txt`），阐述其专有结构切片策略与精准出处定位标签；
2. 明确列出不支持/禁止直接入库的文件类别及底层原因（纯二进制、压缩包、音视频媒体、纯图片、旧版二进制 Office 及 PDF 演进状态），并给出格式转换与操作建议；
3. 完善终端拦截与友好操作提示：当用户输入不支持的格式时，控制台给出明确的格式边界指引与另存为建议；
4. 同步更新 `README.md` 中的系统架构特性（快慢双车道、4 轮 Agent Loop、可编辑 Prompt 模板、维测日志）。

# 范围

## 目录结构

### 修改
- `README.md`: 新增专属章节【二、知识库存储资产边界（可以存什么 vs 不可以存什么）】，并同步更新完整工程架构与模块说明。
- `main.py`: 更新终端 Banner、快速帮助与不支持格式拦截提示，提供直观的格式支持说明与转换建议。
- `tests/test_skeleton.py`: 新增针对存储能力边界提示与不支持格式友好拦截的自动化测试用例。

### 明确不建
- 本次聚焦于能力边界规范与说明强化，不引入新的重型多模态 OCR 或音视频转录库。

# 非目标

- 不改变已有的正常文档解析、向量检索与 4 轮 Agent Loop 逻辑。

- 终端运行及帮助信息明确公示已支持格式范围与边界提示。
