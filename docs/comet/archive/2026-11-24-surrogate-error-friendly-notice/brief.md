# 目标

按照用户明确指示，不进行全链路防御性代码修改，保持底层原生逻辑；
仅在终端交互控制层（`main.py`）中，当捕获到底层抛出关于 UTF-8 代理字符（如 `'utf-8' codec can't encode character '\udce5'... surrogates not allowed`）的异常时：
在控制台高亮打印专门的友好诊断说明，明确告知用户：
**“空格或退格切断了 UTF-8 多字节序列，导致残缺字节被识别成了代理字符（如 \udce5）”**，并提示用户重新完整输入中文字符。

# 范围

## 目录结构

### 修改
- `main.py`: 在终端交互异常捕获流中，针对性识别包含 `surrogates not allowed` 或 `\udce5` 的 `UnicodeEncodeError`，输出友好的排查诊断说明面板。
- `tests/test_skeleton.py`: 增加针对代理字符异常友好拦截与终端说明输出的自动化验证用例。

### 明确不建
- 不修改 `llm/embeddings.py` 或核心库的编码逻辑，完全尊重用户的轻量诊断定位方案。

# 非目标

- 不改变已有的正常问答、检索、Office 导出与入库逻辑。

# 验收示例

- 当系统触发包含 `surrogates not allowed` 或 `\udce5` 的异常时，终端能精准打印定制提示，明确指出“空格切断了 utf-8 字节导致识别成了 \udce5”。
- 全套端到端自动化测试套件继续 100% 通过，沙箱自动销毁无残留。
