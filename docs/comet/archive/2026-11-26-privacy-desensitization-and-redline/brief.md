# 目标

建立项目最高安全级别的【隐私数据隔离与代码文档脱敏红线】，全面清洗工作区代码、测试用例、文档说明及工作区规范中残留的真实业务项目名称、真实业务代号与私有提问：
1. 确保所有实际存入的物理文档、SQLite 数据库文件、成果物以及维测轨迹日志继续受到 `.gitignore` 保护，严禁跟踪与提交；
2. 对 `README.md` 中的示例路径与提问进行彻底脱敏，全部替换为中立通用的虚拟示例（如 `系统架构设计规范.docx`, `设备端开发规范` 等）；
3. 对 `tests/test_skeleton.py` 中的测试文档名与提问语句进行彻底脱敏，全部替换为纯合成的通用中立测试用例（如 `Device_Sensor_Design_ODM_V1.0.md`, `智能终端通信协议` 等）；
4. 清洗代码（`main.py`, `storage/vector_store.py`）注释中的真实私有业务代号；
5. 在工作区根目录确立 `GEMINI.md` 永久安全红线规则，确保后续所有会话与开发者永远严格遵守。

# 范围

## 目录结构

### 修改
- `README.md`: 替换示例中的私有业务名称与路径为中立通用名称。
- `tests/test_skeleton.py`: 替换测试用例中所有涉及真实业务代号与文档名的数据为虚拟脱敏用例。
- `main.py`: 清洗函数注释与 docstring 中的私有示例。
- `storage/vector_store.py`: 清洗注释中的私有业务代号。
- `GEMINI.md`: 确立数据隐私与代码脱敏隔离的永久不可逾越红线。

### 明确不建
- 不改变系统的核心业务算法与逻辑功能。

# 非目标

- 不影响任何单元测试的覆盖率与正确性。

# 验收示例

- 全库检索不再包含任何用户的真实私有业务代号或项目路径。
- 全套 16 项自动化端到端测试用例 100% 通过且全部使用中立虚拟用例。
- `GEMINI.md` 包含不可违背的数据与隐私隔离红线规则。
